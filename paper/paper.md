# EnzymeLyzer Pro: An R/Shiny platform for quantitative enzyme assay analysis and visualization

## Summary

EnzymeLyzer Pro is an open-source web-based application developed using R and Shiny for the analysis of enzyme assay data. The platform provides an integrated workflow for protein estimation, enzyme activity calculation, product concentration determination, specific activity normalization, and qualitative enzyme screening.

The tool supports multi-replicate datasets and incorporates statistical analysis including one-way ANOVA and Tukey’s HSD post-hoc test, enabling robust comparison of enzymatic activity across microbial isolates. Additionally, it generates publication-quality visualizations and includes integrated experimental protocols to support reproducibility.

---

## Statement of Need

Quantitative enzyme assays are widely used in microbiology, entomology, and biochemical research to evaluate enzymatic activity of microbial isolates and biological samples. However, data analysis workflows often involve multiple manual steps including spreadsheet calculations, statistical testing, and graphical visualization, which can be time-consuming and prone to error.

Existing tools lack integration of enzyme-specific workflows, statistical validation, and reproducible protocol guidance within a single platform. EnzymeLyzer Pro addresses this gap by providing a unified, user-friendly interface that automates calculations, supports replication-based analysis, and ensures consistency across experiments.

---

## Features

* Multi-enzyme support (Cellulase, Hemicellulase, Pectinase, Lipase, Invertase, Protease)
* Protein estimation using standard curve regression
* Enzyme activity and specific activity calculation
* Product concentration analysis
* Statistical analysis (ANOVA and Tukey HSD)
* Replication quality assessment (CV%)
* Publication-quality plots
* Integrated enzyme assay protocols
